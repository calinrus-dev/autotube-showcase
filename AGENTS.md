# AutoTube

Responde en español. Lee README y el documento del componente antes de cambios amplios. Este repositorio contiene la demo pública de navegador y documentación seleccionada; el motor Python, Tauri nativo y MCP permanecen en el repositorio privado. Conserva sus contratos públicos sin copiar credenciales, inventarios ni datos de producción. Usa los lockfiles. Para validar la demo: npm ci y npm run verify; comprueba las interacciones y las vistas de escritorio/móvil en navegador. Los controles engine:lint, cargo check y pruebas MCP corresponden al repositorio privado, no a este showcase. No habilitar un proxy hacia el motor privado en la demo. No añadir borrado remoto de YouTube sin petición explícita. No activar servicios recurrentes ni exponer el motor a la red por rutina. No iniciar agentes paralelos salvo petición explícita.
